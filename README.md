# 示例地图：三岔河（Sample Map: Three Fords）

《潮汐前线》（Tidemark）的一个扩展，也是 [DSH 游戏商店](https://dsh-game-store.com)插件工坊的第一个条目。它给游戏加一张 14×10 的两方小地图。

装法：在 DSH 的游戏商店里打开《潮汐前线》的游戏页，在“插件工坊”里点“安装”，再开始游戏。

想自己做扩展：照这个包的样子写，说明见 <https://dsh-game-store.com/workshop/>。`mod/mod.js` 的写法见游戏包里的 `game/mods/README.md`。

This is an extension for Tidemark and the first item in the DSH Game Store workshop: a small two-faction map. Install it from the Workshop section of the game's page in the store.

`mod/mod.js` comes from the game's own example (`mods-examples/sample-map/`); `node scripts/pack.mjs --tarball` copies it and packs the extension.
